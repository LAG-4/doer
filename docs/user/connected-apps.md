# Microsoft connected apps

Microsoft connections are experimental: turn on **Experimental connections** in
**Settings → Connected apps** first. Until then the Microsoft section stays hidden
and new connections are refused, even with a saved sign-in. Disconnecting a
connected account stays available while the switch is off, and your credentials
are kept for re-enabling.

Open **Settings → Connected apps** on the computer hosting your Tasks. Choose
**Connect Microsoft account**, open Microsoft's sign-in page, enter the displayed
code, then return to Doer and check the connection. You can cancel and restart
if the code expires. Company accounts may require an administrator to approve
the connection; Doer explains this and keeps your Task available to retry.

The connection lets Tasks find and read selected Outlook messages, calendar
events, and OneDrive files. Enable SharePoint only if your work needs it; this
requires additional permission. Ask for the file or date range you need. Doer
searches on request and reports source links and retrieval dates. Documents can
be downloaded into the Task's Space to read or compare.

This connection does not send email, submit forms, or edit cloud files. Drafts
and downloaded copies stay local. Content used in a Task is sent to your chosen
AI service, so review that service's privacy policy before using work documents.

If your installation says Microsoft sign-in is not configured, the operator
needs to enable it. You can attach a downloaded document in the meantime.
Disconnect here to remove Doer's saved account credentials from this computer.
If access expires or is revoked, connect again and retry the Task; a retrieval
failure does not mean that no messages or files exist.
