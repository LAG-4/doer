# Reminders

Ask Doer to do work later or repeat it: “Every Monday at 9am, read the bills
in my Money folder and list anything due this week.” You can schedule a single
run, a daily run, or a weekly run. The manual editor also offers weekdays. Include the files or sources to use and the
result you want. If the timezone or timing is unclear, Doer asks before saving it.

Doer can suggest repeating useful work, but it creates a reminder only when you
ask for it or agree to the suggestion. Ask it to show the setup first if you
want to review the details before creation.

Results usually appear in the task where you asked. That task keeps its existing
permissions, so a run can wait for your approval. For work you want kept separate,
ask for a separate task. A separate task starts supervised, so each run waits for
your approval and shows as needing attention in Reminders — unless you explicitly
choose “Work without waiting for me” when creating it, which grants that task full
access. Doer never switches a reminder to full access on its own; editing a reminder
never resets its permissions. A finished run moves its separate task out of Active.
A separate task needs instructions that make sense
without the original chat.

The computer hosting the task must be on with Doer running. After downtime,
a missed reminder runs once when Doer starts again; it does not replay every
missed day. Daily and weekly times follow the saved timezone, including daylight
saving changes.

Use **Reminders** in the sidebar to view the saved timing and open its task.
Choose **New reminder** to describe one in chat or fill in its details yourself.
You can ask in chat to edit, pause, resume, run now, or stop a reminder. Running
now keeps the next scheduled time. Stopping keeps the task and past results;
work already requested can still finish.

Run history records requests to do the work, not proof that it succeeded. Open
the task to read the result or see whether it needs your attention. A one-time
reminder has no more scheduled runs after its request is sent, even while the
work is still running. Email or other external delivery needs its own setup;
results are kept in Doer by default.

## Review a routine before enabling it

After receiving a useful result, choose **Repeat this Task** and describe your
preferred timing. Review the request before sending it. Include which files or
connected accounts to use and what the result should contain.

The manual editor previews a new routine by default. It runs the work once and
keeps the routine paused so you can review the result before resuming. Weekdays
creates five weekly reminders, one for each weekday; pause, edit or remove each
from Reminders. Model and timezone controls are under Advanced.

The latest run distinguishes **Running**, **Needs your attention**, **Failed**
and **Finished**. Open its Task for the actual result. **No more runs** describes
a one-off schedule, not whether the work succeeded. You can run it again even
after the schedule is exhausted. A disconnected account is a failure to retrieve
information, not an empty inbox. Reconnect in Connected apps, then retry.
