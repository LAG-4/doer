# Scheduled tasks

Ask Doer to repeat work, including the timing, files or connected accounts to use,
and the result you want. For example: “Every Monday at 9am, review my bills and
list anything due this week.” You can also create and manage routines in
**Settings → Scheduled Tasks**. Choose a repeating interval or a time of day,
and select the days it should run. Webhooks can trigger work when another service
sends a request.

Tasks can run in the conversation where you created them or start a separate
conversation for each run. Review the selected model, instructions, and permissions
before enabling a routine. Open its conversation to read results or handle an
approval request.

The computer hosting the routine must be on with Doer running. Use the schedule's
controls to pause, resume, edit, run now, or delete it. Deleting a schedule stops
future triggers and keeps the conversations it created.

Existing Doer reminders are carried over automatically. Their saved timezone and
one-time timing are preserved; a one-time reminder disables itself after its run.
